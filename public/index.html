Launcher Release

Update Launcher / เผยแพร่ไฟล์อัปเดต

อัปโหลด ZIP ของ Launcher ที่ Publish แล้ว ผู้เล่นจะได้รับอัปเดตอัตโนมัติเมื่อเปิด Launcher

เวอร์ชันที่เผยแพร่ล่าสุด
กำลังโหลด…

เตรียม ZIP ก่อนอัปโหลด

  1. ใน Visual Studio ใช้ Publish สำหรับ Windows แล้ว ZIP ไฟล์ทั้งหมดในโฟลเดอร์ Publish
  2. ให้ไฟล์ HSH SovereignSoul.exe อยู่ที่รากของ ZIP ไม่ซ้อนในโฟลเดอร์ย่อย
  3. ตั้งเวอร์ชันใหม่ให้สูงกว่าเดิม และอย่าเปลี่ยนชื่อไฟล์ EXE
  4. กดเผยแพร่ — Launcher จะตรวจ SHA-256 และถามก่อนอัปเดต จากนั้นปิดตัวเอง อัปเดตไฟล์ และเปิดใหม่

ไฟล์ ZIP เก็บใน Supabase Storage แบบ private และ Launcher ใช้ลิงก์ชั่วคราวสำหรับดาวน์โหลด
